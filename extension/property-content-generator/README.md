# 🧩 Property AI Content Generator (Chrome Extension Suite)

Extensión de navegador adaptada para **Property OS** para la inyección y generación automatizada por lotes de guiones y videos en **Google Labs Flow** y **Vibes AI**.

Property OS adapta este motor incorporando:
1. **Tokens de Anclaje Visual Inmutable:** Directrices de diseño (`BRAND_GUIDELINES.md` / `HR_MODEL_SHEETS.md` - Obsidian Black `#0B0D12` y Champagne Gold `#D4AF37`).
2. **Generación 9:16 y 16:9 Conmutable:** Formatos para TikTok / Reels y Web / YouTube.
3. **Integración Nativa:** Generación de `script.json` directo desde la plataforma Property OS.

## 🚀 Instalación en Modo Desarrollador en Chrome

1. Abre Google Chrome y ve a `chrome://extensions/`.
2. Activa el interruptor **"Modo de desarrollador"** (arriba a la derecha).
3. Haz clic en **"Cargar descomprimida"**.
4. Selecciona esta carpeta: `c:\Files ECOTRAFFIC A8\PROYECTOS 2026\PROPERTY\Property app\extension\property-content-generator\`.
5. ¡Listo! La extensión quedará anclada en tu barra de extensiones.
